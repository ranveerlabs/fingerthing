# pcb

KiCad 10. Draft based on Raspberry Pi's RP2350A R4/S1 reference.
Local symbols and footprints included. `bash hardware/check.sh` runs ERC and DRC.
USB-C, sensor connector and final layout are still pending. Do not order this.
