# fingerthing

i wanted touchid but not a mac

The goal is a fingerprint reader that can be used as a passkey on any laptop
and OS. This is a hardware project, currently at the planning stage. No hardware
or firmware has been built, and compatibility has not been tested.

The [build journal](JOURNAL.md) records progress and decisions. Board design goes
in [hardware/](hardware/), device code in [firmware/](firmware/), enclosure files
in [case/](case/), and parts and research in [docs/](docs/).
