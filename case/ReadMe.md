# case

Small rounded button, rear USB-C, screws underneath. The PCB is 34 x 48 mm.
The [documented R503 variant](../hardware/sensor.md) is 28 mm wide and 19 mm tall. The earlier SEN0348 enclosure does not fit this parts plan.

Use [immurok](https://github.com/immurok/hardware) as a packaging reference.
Keep the sensor clear of the board and put labeled service pads underneath.
Cable clearance and the supplied module still need a fit check.
